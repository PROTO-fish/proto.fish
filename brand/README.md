# Brand assets

`logo_proto_splash.png` (1254x1254, lossless) is the master. Everything else is derived or a reference copy.

| File | Use |
| --- | --- |
| `logo_proto_splash.png` | Master; source for `scripts/build-icons.sh` |
| `logo_proto_splash.jpg` | Lossy copy of the master |
| `logo_proto_splash_small.png` | Palettized (256 colors) copy |
| `logo_proto_splash_avatar_192.jpg`, `_384.jpg` | Avatars for external profiles |

Site icons (`favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`) are generated: run `scripts/build-icons.sh`. Do not edit them by hand.
